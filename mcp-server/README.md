# mcp-server

FastMCP (Streamable HTTP) server exposing the KB as tools: `get_profile`, `list_projects`, `get_project_evidence`, `get_experience`, `check_fit`, `get_contact_and_availability`.

Scaffolded in Phase 0. Implementation begins in Phase 1 (all tools except `check_fit`) and Phase 2 (`check_fit`), per `../docs/sdlc-plan.md`.
